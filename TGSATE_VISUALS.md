Sources: the shared Google Photos albums "TGSATE" (about 300 images) and "GOKU DRAGON" (Team
Dragon, about 137 images). **Only sampled thumbnails and contact sheets were viewed.** This is a
theme catalogue, not a complete per-image index.

## How the themes attach to ORION

| ORION component | Visual theme | Use |
|---|---|---|
| 13 Levels of Geometric Integration (progression, `RequestProject/Hub/Progression.lean`) | Nested spheres → tori → dodecahedral space | One visual per level, as badges and zone art |
| Education layer | MAD-style covers | "Issue" cards that open a lesson. Each cover's topic (base-9 arithmetic, digital roots, 120-point lattice) links to checked material: `RequestProject/Hub/CubyNumerics.lean`, `RequestProject/Hub/TrinityDigitalRoots.lean` |
| Game layer (MMO) | Team Dragon | A faction and guild identity. Dragon quests can be the Civ One-style build loop |
| Kronos/Orion meters | Tri-Sphere Gear System | Meter art for the three-way balance |
| Evidence ledger | Hand-drawn notebook pages | "Source pages" shown next to each claim, with its status label (observed, replicated, hypothesis) |
| 4th Space / community hub | Holographic multiverse | Lobby and world-map backdrop |

## Rule for use

Artwork shows ideas; it does not count as evidence. When an image carries a numerical claim
(for example "144 = 000" or "5:2"), the in-game card should link to that claim's entry in the
evidence ledger and show its status there.
