Score = max(0, strongest support − strongest challenge) / 1.5. Repeating evidence or adding weaker evidence changes nothing (anti-volume, proved in Lean).
Cross-discipline bridges threshold θ =
A bridge links two claims from different disciplines whose tag sets have Jaccard similarity ≥ θ. Each bridge shows the tags it shares.
13-level path XP per level k =
XP = sum of scores of distinct claims. level = min(13, 1 + ⌊XP / k⌋). Resubmitting the same claim earns nothing.

Immutable snapshots (DAG-CBOR / IPFS)
Each snapshot is encoded as DAG-CBOR and named by its CIDv1 (sha2-256). The same bytes always give the same CID, and any edit changes it. A .car file can be carried offline (sneakernet: USB stick, mail, UUCP-style batch transfer), imported with ipfs dag import, or put on an archive server. Snapshot log (append-only):
    Import
    A .car or .cbor import is re-hashed first and refused if the CID doesn't match its bytes.
